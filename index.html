Transistor Lights
Two-transistor astable multivibrator — a discrete, oscillator-free alternating LED flasher built from first principles, no microcontroller.
2-layer · 1.6mm FR4 THT ERC 0/0

How it oscillates: R3 and R4 bias each BC547's base toward VCC while C1 and C2 cross-couple each transistor's collector into the opposite transistor's base. When Q1 saturates, its collector drop yanks Q2's base low through C2, cutting Q2 off — then the caps slowly recharge through R3/R4 until the roles flip. The result is a self-sustaining flip-flop with no clock or IC.

LEDs as the visible output: D1 and D2 sit in the collector path of Q1 and Q2, so each LED lights only while its transistor is conducting — the two alternate automatically as the multivibrator toggles state.

Routed as a 2-layer, 1.6 mm FR4 board, fully through-hole for hand assembly. ERC and DRC both came back clean (0 warnings, 0 errors).
